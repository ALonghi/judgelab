# Product

## Register

product

## Users

Experienced backend engineers practising Python, sometimes after time in other
languages. Domain vocabulary and Python mechanics need explanation before use.
Source: AGENTS_CONTEXT.md, Primary learner profile and Pedagogical philosophy.

## Product Purpose

Local guided practice: understand a problem, implement Python, run real tests,
inspect feedback, retry and explain decisions. Success means understanding and
working code, not memorizing a reference solution.

## Brand Personality

Clear, encouraging and practical. Reward progress without childish presentation.
The project context names Duolingo, Typeform and interactive coding platforms as
experience references: focused tasks, immediate feedback and easy retries.

## Anti-references

Avoid static exercise dumps, giant metrics dashboards, competitive programming
puzzles, fake AI grades and unexplained terminology. These exclusions come from
AGENTS_CONTEXT.md.

## Design Principles

- Teach the necessary concept before asking for an implementation.
- Make examples concrete and show how inputs produce outputs.
- Keep one focused task and an obvious next action.
- Preserve learner work and reveal solutions only on request after an attempt.

## Accessibility & Inclusion

Readable text and clear hierarchy are essential to the reading and coding loop.
The current task specifically calls out small, low-contrast text. Keep meaning
available in text rather than color alone, and preserve keyboard access and the
existing reduced-motion support.
